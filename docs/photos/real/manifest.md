# Real project photos — manifest

Operator-supplied photographs of **real Sunset Services projects**, archived
here as the source of truth for the live image pipeline (the same role
`docs/stock-bridge/` plays for bridge stock — but these are NOT stock and
have no replace-by date; they replace stock).

Derivatives are generated by `scripts/optimize-real-photos.mjs`
(16:9 hero + 4:3 tile, mozjpeg, adaptive quality — same conventions as the
stock-bridge optimizer). **Never upscale a source beyond ~1.5×**; a
below-standard source ships at a capped hero width and is flagged below for
replacement when the full-resolution original arrives.
